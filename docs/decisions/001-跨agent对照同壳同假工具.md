# ADR-001: 跨 agent 对照必须同壳同假工具——实验11 跳过 opencode 对照

- **状态**：已接受
- **日期**：2026-09-27
- **关联**：无（首个 ADR）

## 背景

实验11 旅游场景按原计划收尾时要做「opencode 对照 k=1~3」。
复核实验10 B5b 对照批轨迹时发现记录级问题：

- opencode 批首条 user 只有**裸话术**，无客服壳 system prompt；
- 工具面是真 `bash/read/skill`，**从未拿到壳里 4 个假工具**（`kb_search` 等）；
- 因此 cs1/cs3 的 3/3「查全全中」是**没工具必然查不全的机械命中**，
  cs8 的 0/3 同理含「调不到 `process_refund`」的机械成分；
  实验10 记录中「同任务集、同壳」的表述不成立（勘误已追加至实验10 记录 §3）。

此时实验11 已 8/8 过可报数门，对照是收尾项而非主项。

## 决策

**实验11 跳过 opencode 对照**（C6 直接落档）；同时确立约定：
**跨 agent 对照 = 同壳 + 同假工具 + 换模型**（bare + `BARE_AGENT_MODEL` 覆盖），
opencode 对照仅在场景工具可用时才允许作方向读数。实验10 勘误按追加式补录。

## 理由与备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **跳过对照（选定）** | 学习期口径（单模型 K≥5）已满足；不产半机械读数；省 2~4h 端点排队 | 实验11 无模型间方向标 | ✅ 采用（用户拍板） |
| 按原计划跑 opencode 对照 | 兑现原计划字面项 | 工具侧 4 题（t1/t4/t5/t8）结构性机械 0/机械命中，只文本侧 4 题可读——重复实验10 的坑 | ❌ |
| bare+mimo 同壳换模型对照 | 真正可比，直接回答「换模型失败谱变不变」 | 未在本轮跑（留 M2） | ⏸ 备选，升级为**标准对照法** |
| 两个都跑 | 信息最全 | 3~4h 端点排队，收尾成本失衡 | ❌ |

**为什么这么定**：机械命中产生的「对照结论」比没有结论更贵——它会进记录被后续引用
（实验10 §4.5 已中招一次）。宁可少一个对照，也不产出读不了的对照。

## 后果

- 正面：实验11 保持单模型纯口径落档；「同壳换模型」成为后续对照的标准姿势写入 ADR；
  实验10 历史结论含机械成分的部分被显式降级，防止继续引用。
- 代价/风险：实验11 缺模型间方向标；若后续阶段要补，用 `BARE_AGENT_MODEL=<目标模型>`
  同任务集同指纹重跑对照批（两批须同时满足 `compare` 可比四条件）。
- 重评条件：出现能让 opencode/其他 agent 使用场景假工具的机制（如 MCP 壳桥）时，
  opencode 对照可恢复，但须先证明「工具面一致」再跑。
