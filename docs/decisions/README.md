# 架构决策记录（ADR）索引

一个决策一个文件，三位数编号递增：`NNN-短横线标题.md`。

## 规则

- 什么算「重大决策」：技术选型、目录/模块结构、数据模型、外部依赖引入、影响多个模块的约定
- 已接受的 ADR **不修改**：推翻时新建 ADR 并把旧文件状态改为「已取代（→ 新编号）」
- 重点写「理由与备选方案」：实现细节会过时，为什么这么选是交接时最贵的信息
- 模板见 `template.md`；生成新 ADR 可直接让 agent 按 template 创建
- 历史决策（本体系建立前）**不批量回溯补写**：只挑有「为什么」价值的关键决策手写 ADR（状态标「已接受」、日期标追溯），其余在活文档中声明位置即可
