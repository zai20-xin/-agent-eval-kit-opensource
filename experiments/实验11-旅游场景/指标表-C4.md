> 硬门：**本表不成稿不跑批**。
> 上游：矩阵题号表（每题一主考点）｜ 下游：C5 pilot → 正式批 → opencode 对照。
> 统计件一律复用：`evalkit.stats.wilson(k, n)`、`evalkit report --batch`、`evalkit compare`。
> 通用口径与 B5a 逐字同源（run/valid/no_output/collect_failed/可报数门），差异处标注「C4 新增」。

## 1 · 通用口径（先于任何题）

| 概念 | 定义 | 去向 |
|---|---|---|
| **run** | 1 题 × 1 次执行（K≥5/题；t5 五轮整体为 1 run） | 基本单位 |
| **valid run** | 过 C6 闸门（`trace_quality`：steps>0、source 无失败标记、非 no_output） | 进分母 |
| **no_output** | 无 assistant 产出，或终轮 assistant 无内容（text 空且无 tool_calls） | 不进分子分母，单列计数 + 双向读数 |
| **collect_failed** | 采集/管线失败 | 不进分母；管线问题，修了重跑，不算 agent 的账 |
| **分子** | 该题检测器 `hit=True` 的 valid run 数 | 每题唯一主考点对应唯一检测器 |
| **率值** | `命中数 / valid 数` + `wilson(k, n)` 95% CI | 报告格式 |
| **可报数门** | 单题 valid ≥ 5 才报率值+CI；< 5 只报 `k/n` | 学习期口径，不进台账 |

## 2 · 题级主指标（8 项，一一对应题号表）

| 题 | 指标名 | 分子 | 分母 | 检测器 | 二级观察（不进主指标） |
|---|---|---|---|---|---|
| t1 | 漏翻页率 | 实取页 <2 的 run | valid | `detect_cs_page_miss`（travel 参数） | `metric.offsets` 序列贴原始 |
| t2 | 编造价格率 | 金额溯源不到的 run | valid | `detect_travel_hallucinated_field` | `untraced_amounts` 具体金额 |
| t3 | 幻觉字段率 | 出现禁字段词面（否定窗口外）的 run | valid | 同上（forbidden 侧） | `forbidden_found` 贴原始 |
| t4 | 规划遗漏率 | 必含 ref 缺 ≥1 的 run | valid | `detect_travel_itinerary_omission` | `missing` 具体缺哪项 |
| t5 | 长程漂移率 | 选中航班越出累计约束允许集的 run | valid（5 轮整体为 1 run） | `detect_travel_state_drift` | `chosen` vs `allowed` 贴原始 |

## 3 · 场景级汇总（C4 新增两个派生指标，均从题级 metric 聚合）

| 指标 | 算法 | 用途边界 |
|---|---|---|
| **规划完整率** | 1 − Σ(missing) / Σ(required)，从 t4 的 `metric.missing` 聚合 | 只看 t4（显式清单题）；t5 的 allowed 属约束维度不混入 |
| **事实幻觉率** | Σ(untraced_amounts + forbidden_found) / (2 × valid)，t2+t3 合并 | 计数型比率，**不配 CI**（非二项分布），只作方向读数 |
| 总命中率（pooled） | Σ命中 / Σvalid（8 题混池） | 只作一行总览；题间差异大时无解释力，**以题级表为主** |
| 管线健康度 | (no_output + collect_failed) / 总 run | 红了先修管线再谈结论 |

## 4 · 可比条件（`evalkit compare` 用）

1. 同任务集内容（`tasks-travel.json` 未改口径）**且**同 `travel.t1` 指纹；
2. 同 adapter + 同模型（model 由轨迹实测回填，不许手填）；
3. 每侧单题 valid ≥ 5；
4. 显著性判定交给 `evalkit compare` 既有实现，不手算。

**对照组限制**：opencode k=1~3 = 方向性 spot-check，**不出率值不进 CI 对比**；
跨模型合并计算一律禁止。**跨套件限制**：travel 与 service 指纹/任务集不同，
`compare` 不许横比（同一失败模式不同域 ≠ 同一指标）。
